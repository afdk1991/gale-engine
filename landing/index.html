核心功能

十大模块覆盖日常性能优化全流程

📊

硬件监控

实时采集 CPU / 内存 / 磁盘 / 网络负载、温度与电量，每秒刷新。

⚙️

进程管理

查看进程 CPU / 内存占用，结束、挂起 / 恢复进程，调整优先级（系统进程已保护）。

🧹

垃圾清理

扫描 Temp、回收站与浏览器缓存占用，白名单安全清理，逐项回执、失败隔离。

⚡

启动项管理

集中管理 HKCU / HKLM 开机启动项，一键启用 / 禁用。

🎮

游戏模式

一键切换高性能电源计划，退出时自动还原，安全可逆。

🌐

网络诊断

Ping 延迟测试（最小 / 平均 / 最大 / 丢包率）与本机网卡信息。

🖥️

服务管理

查看 Windows 服务状态与启动类型，启动 / 停止、切换自动 / 手动 / 禁用（系统关键服务已保护）。

⏰

计划任务

枚举系统计划任务与运行时间，启用 / 禁用、立即运行、结束运行中任务。

🛡️

防火墙

Domain / Private / Public 三配置文件开关，规则列表查询与单条规则启用 / 禁用。

🧰

系统工具箱

刷新 DNS、清空回收站、清空剪贴板、切换深色模式，幂等安全。

🕘

优化记录

每次清理 / 模式切换自动留痕，时间线一目了然。

如何获取安装包

两种方式，任选其一

🛠️

方式一：本地一键构建

克隆仓库后运行 scripts/package-win.cmd（需 Node 与 7-Zip），自动产出 release/gale-engine-0.4.0-setup.exe。镜像源已默认指向国内 npmmirror，无需翻墙。

📦

方式二：Release 下载

推送 v*.*.* tag 即由 .github/workflows/release.yml 自动构建并发布。直接前往 GitHub Releases 下载 gale-engine-0.4.0-setup.exe（NSIS，支持自定义安装目录），双击即可安装。

✅

安装与验证

安装后从桌面 / 开始菜单启动，按 docs/smoke-test-checklist.md 逐项核验十大模块功能。
