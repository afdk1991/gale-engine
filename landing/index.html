如何获取安装包

两种方式，任选其一

🛠️

方式一：本地一键构建

克隆仓库后运行 scripts/package-win.cmd（需 Node 与 7-Zip），自动产出 release/疾风引擎-0.2.0-setup.exe。镜像源已默认指向国内 npmmirror，无需翻墙。

📦

方式二：Release 下载

推送 v*.*.* tag 即由 .github/workflows/release.yml 自动构建并发布到 GitHub Releases。发布后访问 https://github.com/<owner>/<repo>/releases 获取安装包（NSIS，支持自定义安装目录），双击即可安装。

✅

安装与验证

安装后从桌面 / 开始菜单启动，按 docs/smoke-test-checklist.md 逐项核验六大模块功能。
