多种安装方式

按平台选择最适合的方式，命令行用户与普通用户都能轻松上手

🥄

Windows · Scoop

命令行用户首选，自动管理版本与升级：

scoop bucket add gale https://github.com/afdk1991/gale-engine
scoop install gale-engine

支持 x64 + arm64 · scoop update 即可升级

🍺

macOS · Homebrew

命令行用户首选，自动按 CPU 架构选择 DMG：

brew tap afdk1991/gale-engine
brew install --cask gale-engine

支持 Intel + Apple Silicon · 首次打开需右键 → 打开

📦

Linux · AppImage / deb

AppImage 免安装即用，deb 适用 Debian/Ubuntu：

# AppImage（x64 / arm64）
chmod +x gale-engine-*.AppImage && ./gale-engine-*.AppImage

# deb（x64）
sudo dpkg -i gale-engine-*.deb
⬇️

直接下载安装包

上方下载区按你的系统推荐对应包，或前往 GitHub Releases 下载全部产物。双击即可安装，无需命令行。

🛠️

本地一键构建

克隆仓库后运行 npm run package:win / :mac / :linux（需 Node），自动产出对应平台安装包。镜像源已默认指向国内 npmmirror，无需翻墙。

✅

安装与验证

安装后从桌面 / 开始菜单 / Launchpad 启动，按 docs/smoke-test-checklist.html 逐项核验全部模块功能（72 项，含 44 项实机 GUI 冒烟）。

常见问题

安装与使用中的高频问题解答

Windows 安装时 SmartScreen 提示「未知发布者」怎么办？

这是因为应用未配置代码签名证书。点击「更多信息」→「仍要运行」即可安装。这不影响功能与安全，只是 Windows 对未签名应用的常规提示。配置证书后 CI 会自动签名，提示将消失。

macOS 打开时提示「无法验证开发者」怎么办？

右键点击应用图标 → 选择「打开」→ 在弹窗中点击「打开」。也可以在终端执行 xattr -d com.apple.quarantine /Applications/疾风引擎.app。配置 Apple Developer 证书后 CI 会自动签名+公证。

Linux AppImage 双击没反应？

AppImage 需要先赋予执行权限：在终端运行 chmod +x gale-engine-*.AppImage，然后 ./gale-engine-*.AppImage 即可启动。也可以在文件管理器中右键 → 属性 → 权限 → 勾选「允许执行」。

Scoop / Homebrew 安装后如何更新？

Scoop：运行 scoop update gale-engine 即可升级到最新版。Homebrew：运行 brew upgrade --cask gale-engine。两个 manifest 都配置了 checkver / 自动版本检测，新版本发布后即可升级。

应用支持哪些系统？ARM 设备能用吗？

支持 Windows 10/11、macOS 11+、主流 Linux（需 systemd）。同时支持 x64（Intel/AMD）和 arm64（Apple Silicon / Surface / 树莓派 / ARM 服务器），共 6 个平台组合，CI 全量构建。

如何从源码本地构建？

克隆仓库后运行 npm install 安装依赖，然后按平台运行 npm run package:win / :mac / :linux。镜像源已默认指向国内 npmmirror，无需翻墙即可下载 electron-builder 二进制依赖。

应用需要联网吗？

核心功能完全离线运行，无需联网。仅「检查更新」功能需要访问 GitHub Releases（可在设置中关闭自动检查）。

停止系统服务 / 修改防火墙时提示权限不足？

这些操作需要管理员权限（Windows UAC / macOS root / Linux root）。请以管理员身份运行应用，或使用系统服务管理的替代命令。应用对关键系统服务有保护机制，不会允许停止受保护的服务。
