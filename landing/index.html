核心功能

十三大模块覆盖日常性能优化全流程，三平台原生支持

📊

硬件监控

实时采集 CPU / 内存 / 磁盘 / 网络负载、温度与电量，每秒刷新。

🔧

硬件信息

主板 / CPU / 内存 / 显卡 / 显示器 / 硬盘 / 电源 型号规格采集（跨平台）。

⚙️

进程管理

查看进程 CPU / 内存占用，结束、挂起 / 恢复进程，调整优先级（系统进程已保护）。

🧹

垃圾清理

扫描 Temp、回收站与浏览器缓存占用，白名单安全清理，逐项回执、失败隔离。

⚡

启动项管理

集中管理开机启动项（Win 注册表 / mac launchd / Linux XDG），一键启用 / 禁用。

🎮

游戏模式

一键切换高性能模式（Win 电源计划 / mac 防休眠 / Linux CPU 调速器），退出自动还原。

🌐

网络诊断

Ping 延迟测试（最小 / 平均 / 最大 / 丢包率）与本机网卡信息。

🖥️

服务管理

查看系统服务状态与启动类型，启动 / 停止、切换自动 / 手动 / 禁用（关键服务已保护）。

⏰

计划任务

枚举系统计划任务与运行时间，启用 / 禁用、立即运行、结束运行中任务。

🛡️

防火墙

配置文件开关（Win NetFirewall / mac pfctl / Linux ufw）+ 规则列表与启用 / 禁用。

🧰

系统工具箱

刷新 DNS、清空回收站、清空剪贴板、切换深色模式，按平台分发命令，幂等安全。

🕘

优化记录

每次清理 / 模式切换自动留痕，时间线一目了然。

如何获取安装包

两种方式，任选其一

🛠️

方式一：本地一键构建

克隆仓库后运行 npm run package:win / :mac / :linux（需 Node），自动产出对应平台安装包。镜像源已默认指向国内 npmmirror，无需翻墙。

📦

方式二：Release 下载

推送 v*.*.* tag 即由 .github/workflows/release.yml 在 6 矩阵（win/macos/linux × x64/arm64）上并行构建并发布。上方下载区按你的系统推荐对应包，或前往 GitHub Releases 下载全部产物。

✅

安装与验证

安装后从桌面 / 开始菜单 / Launchpad 启动，按 docs/smoke-test-checklist.html 逐项核验全部模块功能（72 项，含 44 项实机 GUI 冒烟）。
