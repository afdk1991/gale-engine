### 两条可复用经验

1. **GitHub Release 资产的 `digest` 字段就是文件内容 SHA256**。
   `gh release view <tag> --json assets` 直接拿到，**无需下载几百 MB 实测**。
   已用最小的 `latest.yml` 交叉验证：API digest 与 `Get-FileHash` 结果逐字符一致。
2. **非交互会话 `git push` 会因 GCM 弹不出认证而 exit 128**（本项目 remote 是 HTTPS + git-credential-manager）。
   解法：用 gh 的 OAuth token 注入 Authorization 头再 push，亲测可用：
   ```powershell
   $b64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes("x-access-token:$(gh auth token)"))
   $env:GIT_CONFIG_COUNT=1
   $env:GIT_CONFIG_KEY_0="http.https://github.com/.extraheader"
   $env:GIT_CONFIG_VALUE_0="AUTHORIZATION: basic $b64"
   $env:GIT_TERMINAL_PROMPT="0"
   git push origin master
   ```
   另注：PowerShell 工具在该环境**不回显 stdout**，需将命令输出 `Out-File` 后再用 Read 工具读取；
   Bash 工具则出现 PATH 损坏（`dirname`/`head` not found），优先用 PowerShell。
   git 中文输出在控制台呈乱码（UTF-8 被按 GBK 解），但文件本身完好——校验提交信息应读 `.git/COMMIT_EDITMSG`。
