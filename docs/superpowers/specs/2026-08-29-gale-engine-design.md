# 疾风引擎（GaleEngine）设计文档

日期：2026-08-29
状态：待审阅

## 1. 产品概述

**疾风引擎**是一款 Windows 桌面优化加速软件，基于 Electron 构建。产品整合三种形态：

- 一键加速首页（小白友好的大按钮 + 健康评分）
- 侧边栏工具箱骨架（功能导航清晰、可扩展）
- 硬件监控仪表盘（实时指标 + 性能曲线，面向进阶用户）

**核心原则**：全部功能真实可用——读取真实系统数据、真正执行清理/释放/优化操作，不做模拟数据。

## 2. 页面结构（共 7 页）

| # | 页面 | 内容 |
|---|---|---|
| 1 | 首页 | 健康评分环（0-100）+「立即加速」大按钮 + 三项关键指标（垃圾量 / 内存占用 / 启动项数） |
| 2 | 硬件监控 | CPU / 内存 / 磁盘 / 温度实时卡片 + 性能曲线（ECharts，60s 滚动窗口）+ 优化建议列表 |
| 3 | 优化中心 | Tab 切换三个子模块：垃圾清理（分类扫描→勾选→清理→报告）、内存加速（进程列表 + 一键释放 + 结束进程）、启动项（注册表 Run 键开关 + 影响评估） |
| 4 | 游戏模式 | 一键组合动作：释放内存 + 屏蔽后台 Windows 更新 + 切换性能优先电源计划；游戏结束恢复 |
| 5 | 工具箱 | 8 个工具：大文件查找、重复文件清理、注册表清理、弹窗拦截、系统信息、网络测速、磁盘分析、文件粉碎 |
| 6 | 优化记录 | 历史清理总量、累计释放内存、评分变化曲线（本地 JSON 文件存储） |
| 7 | 设置 | 主题定制（3 外观模式 × 6 主题色）、清理规则、开机自启与托盘、关于 |

## 3. 技术架构

```
┌──────────────────────────────────────────────┐
│ 渲染进程（Vue 3 + Vite）                       │
│  · 7 个页面组件（vue-router）                  │
│  · 主题系统（CSS 变量驱动）                    │
│  · 图表：ECharts 按需引入（仅折线/仪表模块）     │
│  · 轻图形：评分环等用原生 SVG 自绘              │
├───────────── contextBridge IPC ───────────────┤
│ 主进程（Node.js）                              │
│  · 系统监控：systeminformation（1s 轮询）       │
│  · 垃圾清理：安全目录扫描器（白名单保护）        │
│  · 启动项：winreg 读写注册表 Run 键            │
│  · 内存加速：进程枚举 + 工作集释放              │
│  · 游戏模式：电源计划切换 + 更新暂停            │
│  · 评分引擎：指标加权计算                       │
│  · 数据持久化：electron-store（设置）+ JSON（记录）│
└──────────────────────────────────────────────┘
```

### 技术选型理由

- **Electron + Vue 3**：四个候选（Vue / React / 无框架 / Tauri）中，Node.js 生态的注册表、进程管理、系统监控库最全，中文资料最多，开发风险最低
- **轻量化措施**（吸收 Tauri / 无框架方案的优点）：
  - ECharts 按需引入（只打包用到的图表模块）
  - 评分环、指标卡等简单图形用原生 SVG/Canvas 自绘，零依赖
  - electron-builder 打包启用 asar 压缩、排除多余 locales
  - 目标安装包体积：50-60MB（默认 Electron 打包约 80MB）
- **打包**：electron-builder → NSIS 安装包（exe）
- **托盘**：最小化到托盘；托盘菜单含「一键加速」快捷入口

## 4. 主题系统

- **外观模式**：浅色 / 深色 / 跟随系统（默认跟随系统）
- **主题色**（6 色，用户可切换，默认科技蓝）：
  科技蓝 `#3b82f6` · 极客青 `#06b6d4` · 活力紫 `#8b5cf6` · 健康绿 `#10b981` · 能量橙 `#f97316` · 渐变蓝紫（`#2563eb → #7c3aed` 线性渐变，应用于按钮/评分环等强调元素）
- **实现**：CSS 变量驱动（`--accent` 等令牌），切换即时生效并经 electron-store 持久化

## 5. 评分引擎

```
健康评分 = 100
  − 垃圾文件扣分（按 GB 量阶梯，上限 30）
  − 内存压力扣分（占用率超 70% 起阶梯扣，上限 30）
  − 启动项冗余扣分（超过 10 个起每个扣 2，上限 20）
  − 磁盘空间扣分（系统盘剩余 < 10% 起扣，上限 20）
```

「一键加速」组合动作 = 清理勾选的垃圾 + 释放可回收内存 + 禁用用户确认的高风险启动项，完成后重新评分并展示提升幅度。

## 6. 安全设计（硬性约束）

1. **垃圾清理**：仅扫描白名单安全目录（系统临时、浏览器缓存、缩略图缓存、回收站等）；删除前逐项确认（默认全选安全项）；文件先进回收站或备份目录，支持撤销
2. **内存加速**：系统关键进程白名单保护（systemd 级进程、安全软件等不可结束）；「结束进程」需二次确认
3. **启动项**：优先读写 HKCU Run 键；HKLM 项在无管理员权限时只读展示并提示；所有改动记录在优化记录中，可一键还原
4. **游戏模式**：退出游戏模式自动恢复原电源计划与更新设置；异常退出时下次启动检测并恢复
5. **文件粉碎**：独立工具页显著位置警示不可恢复

## 8. 风险与简化项

- **注册表清理 / 弹窗拦截**：实现复杂度高，v1 做基础版（常见注册表残留项规则库、已知弹窗进程规则库），界面上如实标注「基础规则库」
- **CPU 温度**：部分主板/系统不支持读取，不支持时显示「—」而非错误
- **管理员权限**：需要 UAC 的操作（HKLM 写入、电源计划）在无权限时降级为只读提示；应用可选「以管理员身份运行」重启
- **杀毒软件误报**：未签名 exe 可能被 SmartScreen/杀软警告，v1 通过 electron-builder 配置缓解，正式签名列入 v1 之后规划
- **多语言**：v1 仅中文，界面文案集中管理为后续 i18n 预留

```
│  ├─ main.ts          # 窗口/托盘/生命周期

├─ electron-builder.yml
└─ package.json
```
