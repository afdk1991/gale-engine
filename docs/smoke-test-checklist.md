# 疾风引擎 — 发布前冒烟与检查清单

> 适用范围：每次发版（含 `v0.x` 小版本）前的质量门禁。
> 沙箱限制：本环境无法运行 Electron GUI，GUI 相关项标注「⚙️ 需 Windows 实机」，由发布人在真实 Windows 上执行；纯逻辑/构建项已在沙箱通过单测与 `electron-vite build` 验证。

## 一、构建与门禁（沙箱可验 ✅）

- [ ] `npm run typecheck`（`vue-tsc --noEmit`）零错误
- [ ] `npm run test`（`vitest run`）全绿（当前 54 项）
- [ ] `npm run build`（`electron-vite build`）主进程/预加载/渲染产物均生成，无报错
- [ ] 版本号 `package.json#version` 与计划发版号一致（当前 `0.1.0`）
- [ ] 无遗留 `electron.vite.config.*.mjs` 等构建缓存文件（已加入清理）

## 二、安装包产出（沙箱可验 ✅）

- [ ] 执行 `scripts/package-win.cmd` 产出 `release/疾风引擎-${version}-setup.exe`
- [ ] 安装包为合法 NSIS（PE 头 `MZ`、含 `NullsoftInst` 区段）
- [ ] 镜像源 `ELECTRON_BUILDER_BINARIES_MIRROR` 带结尾斜杠（国内 `npmmirror` 同构路径）
- [ ] 复现性：在干净目录重跑一次，产物时间戳/大小一致

## 三、GUI 冒烟（⚙️ 需 Windows 实机）

### 启动与导航
- [ ] 双击 `疾风引擎-${version}-setup.exe` 完成安装（支持自定义目录）
- [ ] 桌面/开始菜单快捷方式可启动应用，主窗口正常显示（1080×720）
- [ ] 左侧 7 个导航项均可点击，路由切换无白屏：首页 / 硬件监控 / 优化中心 / 游戏模式 / 工具箱 / 优化记录 / 设置
- [ ] 窗口关闭后重新打开，主题（外观/强调色）设置保持

### 硬件监控（Monitor）
- [ ] 进入后每秒刷新一次；CPU 负载、内存占用、网络速率、温度/电量/运行时长均有数值
- [ ] 磁盘列表显示各盘占用百分比；无任何字段为 `NaN` 或异常负值

### 优化中心（Optimizer）
- [ ] 「重新扫描」能列出 Temp/回收站占用与大小
- [ ] 勾选安全项 → 「清理选中项」回执成功计数；非安全路径项被禁用不可勾选
- [ ] 「启动项管理」列出 HKCU/HKLM 启动项；禁用/启用切换后状态即时更新
- [ ] 上述操作均在「优化记录」中留痕

### 游戏模式（GameMode）
- [ ] 「进入游戏模式」后状态切换为已开启，提示切换到高性能计划
- [ ] 「退出游戏模式」还原进入前的电源计划，状态回到普通模式
- [ ] （验证）`powercfg /getactivescheme` 在高性能与普通计划间切换正确

### 工具箱（Toolbox）
- [ ] 刷新 DNS / 清空回收站 / 清空剪贴板 / 深色·浅色 四个工具均给出成功反馈
- [ ] 失败场景（如权限不足）显示红色错误原因，不崩溃
- [ ] 每个成功工具在「优化记录」中留痕

### 设置与记录
- [ ] 外观（系统/浅色/深色）、强调色切换即时生效并持久化
- [ ] 「优化记录」时间线按时间倒序；「清空记录」后列表为空

## 四、发布与托管（EdgeOne Makers）

- [ ] 落地页（静态站点）含：版本徽章、`下载安装包` CTA、功能亮点、更新日志
- [ ] 落地页经 EdgeOne Makers 部署得到公开 URL
- [ ] 安装包制品随发版归档（Release / 对象存储），下载链接与落地页 CTA 对齐
- [ ] 更新日志（CHANGELOG）补充本次发版条目，包含已知限制（沙箱无法 GUI 直测）

## 五、回滚与异常

- [ ] 安装包提供卸载入口，卸载后无残留服务/计划任务
- [ ] 若某模块在实机异常，优先回退该模块 IPC 注册，不阻断主窗口启动
- [ ] 发布后保留 `v0.1.0` tag，便于对照基线

---
> 已知限制：本沙箱为命令行环境，无显示器/Windows GUI，所有 GUI 交互依赖发布人在 Windows 实机按本清单核验；service 层逻辑（含 PowerShell 命令构造）已通过可注入 ExecRunner 的 vitest 全量覆盖。
