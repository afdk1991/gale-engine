## 疾风引擎 v0.1.12

本版是 v0.1.11「全自动升级」的 UI 收尾：下载完成后主进程已会自动退出并安装重启，**界面文案仍停留在旧的需要手动点安装的语义**，会误导用户以为还要再点一次。本版把三处状态文案与实际行为对齐。

### 修复

- **更新卡片文案与「自动重启」行为对齐**（`src/components/UpdateCard.vue`、`src/composables/useAppUpdate.ts`）：
  - `downloaded` 态状态行由「vX 已下载，可立即安装」改为「**vX 已下载，即将自动重启…**」——如实反映倒计时后会自动重启，而不是暗示还需要用户操作。
  - 主按钮「立即安装并重启」简化为「**立即重启**」：安装由主进程自动触发，按钮的实际语义只是跳过等待立即重启，原文案把它描述得像一个必需的安装步骤。
  - 提示行改为「下载完成，即将自动重启以完成升级。也可点「立即重启」跳过等待。」，说明自动重启与手动跳过两条路径的关系。
  - 至此 v0.1.11 埋下的「伪手动」出口被彻底消除：用户即便什么都不点，升级也会完成。

### 说明

- 本版仅改渲染层文案与提示，**不涉及更新逻辑改动**；自动安装行为本身由 v0.1.11 的 `update.electron.ts` 提供。

---

已安装用户可在「设置 → 关于」中检查更新，或直接下载上方安装包覆盖安装。
